The Learning Pathway

Four stages. Zero to maker.

A carefully scaffolded journey — each stage builds real skills on top of the last, ending with projects that sense, think and move.

STAGE 01

Scratch

Coding Basics

Visual programming fundamentals — logic, loops, events and animations — taught through games students build themselves.

STAGE 02

Tinkercad

Virtual Electronics

Circuits, sensors and Arduino simulation in a safe virtual lab. Wire it, code it and watch it run — before touching hardware.

STAGE 03

mBlock

Real Hardware

Program real robots with mBlock. Motors, LEDs, ultrasonic sensors and buzzers come alive with the code students write.

STAGE 04

Capstone

Advanced Projects

Smart Dustbins, Obstacle-Avoiding Cars and more — students design, build and present complete working inventions.
